# frontend-client — the generated SDK

**Covers:** `frontend/src/client/**/*.ts`
**Tier:** infra
**Service:** frontend
**Connects:** backend-http via sync-call

## Purpose

The typed HTTP client the rest of the frontend calls. **It is generated, not written**:
`sdk.gen.ts:1` says `// This file is auto-generated by @hey-api/openapi-ts`, and `types.gen.ts` and
`schemas.gen.ts` alongside it come from the same run.

## Key abstractions

**The backend's OpenAPI schema is the source of truth.** `scripts/generate-client.sh` imports the FastAPI
app, serialises `app.openapi()` (`:7`), moves the JSON into `frontend/` (`:9`) and regenerates
(`:11`). Nothing in this directory should ever be hand-edited; an edit survives exactly until the next
generation.

**This is the cross-language contract, and it is checkable.** Where a hand-maintained type file drifts
silently, a stale client here shows up as a diff in a generated file — someone regenerating gets a change
they did not write, which is a visible signal rather than a runtime surprise.

**One base URL, set once.** `main.tsx:16` assigns `OpenAPI.BASE = import.meta.env.VITE_API_URL`, so the
backend's address is a build-time environment variable and appears in exactly one place.

## State and tiering

None. `core/` holds the request machinery (`CancelablePromise`, the `OpenAPI` config object).

## Invariants

- CLIENT-001 — nothing under `frontend/src/client/` is hand-edited. Structurally true: the files carry a
  generated-by header, and the next `generate-client` run discards any edit.
